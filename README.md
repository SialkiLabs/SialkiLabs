**Sialki Labs** is an AI software research lab committed to building high-performance, privacy-first, local-first systems — from self-healing bridges between cutting-edge generative AI models and local developer tools (Hermes Agent, Antigravity IDE, Cursor, Claude Desktop, and DAWs) to a fully sovereign AI operating system.

## 🚀 Flagship: SIALKI CORE Agent OS *(in active development)*

> **A privacy-first, local-first AI operating system — intelligence on-device by default.**

* **SIALPHAW Kernel**: Rust + C++ security kernel with hash-chained audit logs, structural PII cloaking, and SQLCipher-encrypted storage.
* **Enterprise-grade stack**: Go cloud gateway, Rust engines, C++ mobile core, TypeScript applications — one monorepo for Android, iOS, Windows, macOS, Linux, and Web.
* **12-gate CI**: leak suites, injection corpora, crash injection, golden-doc compliance, performance budgets, secret scanning, and SBOM generation.

Data never leaves the device unless the user explicitly chooses hybrid mode.
